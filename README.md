# เช็กถนนน้ำท่วม ทั่วไทย

เว็บเช็กถนนที่มีน้ำท่วมหรือน้ำขังทั่วประเทศไทยก่อนออกเดินทาง จุดไหนผ่านได้ จุดไหนผ่านไม่ได้

## ฟีเจอร์

- สรุปจำนวนจุดที่ **ผ่านไม่ได้ / ผ่านได้** และจำนวนจังหวัด
- ค้นหาด้วยชื่อถนน อำเภอ หรือเลขทางหลวง, เลือกจังหวัด, แท็บแยกตามสถานะ (ผ่านไม่ได้ / ผ่านได้ / ยังไม่ยืนยัน)
- แผนที่และรายการ เรียงจากจุดที่ผ่านไม่ได้ก่อน กดรายการเพื่อดูรายละเอียด (ช่วง กม., สาเหตุ, เบอร์ติดต่อหมวดทางหลวง) และเปิดใน Google Maps
- ปุ่ม **ใกล้ฉัน** เรียงจากจุดที่ใกล้ที่สุด พร้อมระยะทาง
- โหลดข้อมูลใหม่ทุก 2 นาที, รองรับมือถือ, สลับโหมดสว่าง/มืด

### วางแผนเส้นทาง (`route.html`)

- ใส่ต้นทาง/ปลายทาง (พิมพ์ชื่อเขต อำเภอ จังหวัด, ใช้ตำแหน่งของฉัน หรือแตะบนแผนที่) และเลือกประเภทรถ
- ตรวจรายงานน้ำท่วมที่อยู่ห่างจากเส้นทางไม่เกิน 150 ม. ถ้าทุกเส้นผ่านจุดที่รถคันนั้นไม่ควรผ่าน จะขอ**เส้นเลี่ยง**โดยกันพื้นที่รัศมี 150 ม. รอบจุดเหล่านั้น (สูงสุด 10 จุด ตามขีดจำกัดของ Valhalla สาธารณะ)
- ผลสรุป: ✅ ไม่พบน้ำท่วม · ⚠️ ไปได้แต่มีน้ำ · ⛔ เลี่ยงไม่ได้ (บอกว่าผ่านไม่ได้ หรือรถเล็กไม่ควรผ่าน) พร้อมรายการจุดตามลำดับ กม. บนเส้นทาง
- ระดับสี: 🔴 ผ่านไม่ได้ / รถเล็กผ่านไม่ได้ / น้ำ ≥20 ซม. · 🟠 น้ำ 10–20 ซม. / ผ่านได้ระวัง · 🟡 น้ำ <10 ซม. · ⚪ ยังไม่ยืนยัน (ตัวเลขความลึกมีเฉพาะเซ็นเซอร์ กทม.)
- **รถเก๋ง/รถเล็ก** เลี่ยงจุดผ่านไม่ได้ + รถเล็กผ่านไม่ได้ + น้ำ ≥20 ซม. · **กระบะ/รถสูง** เลี่ยงเฉพาะจุดผ่านไม่ได้
- เรียงเส้นทาง: จุดที่ไม่ควรผ่านน้อยที่สุดก่อน แล้วชั่งเวลากับความเสี่ยง (จุดมีน้ำที่ผ่านได้ ≈ 3–6 นาทีต่อจุด)
- ปุ่มนำทางด้วย Google Maps ใส่จุดผ่าน 3 จุดจากเส้นเลี่ยง ให้ Google วิ่งตามเส้นเดียวกัน · ลิงก์หน้าแชร์ได้ (ต้นทาง/ปลายทางอยู่ใน URL)

## แหล่งข้อมูล

| แหล่ง | ข้อมูล | เรียกผ่าน |
| --- | --- | --- |
| [Longdo Traffic](https://traffic.longdo.com) (มูลนิธิ iTIC) | เหตุการณ์น้ำท่วมทั่วประเทศ จากรายงานของกรมทางหลวงและผู้ใช้ | `/api/thai-roads` → `https://event.longdo.com/feed/json` |
| [Valhalla](https://valhalla1.openstreetmap.de) (FOSSGIS, ข้อมูลถนน OpenStreetMap) | คำนวณเส้นทางและเส้นเลี่ยง | `POST /api/route` |
| [Photon](https://photon.komoot.io) (Komoot) | ค้นหาสถานที่ | `/api/geocode?q=` |
| สำนักการระบายน้ำ กทม. ผ่าน [POPNIX Flood](https://flood.pop.in.th/api/) | เซ็นเซอร์น้ำบนถนนและอุโมงค์ใน กทม. (แสดงเฉพาะจุดที่มีน้ำ) | `/api/roads` → `https://flood.pop.in.th/api_roads.php` |

> **ก่อนเปิดใช้จริง** ควรติดต่อ Longdo / มูลนิธิ iTIC เพื่อขออนุญาตและยืนยันรูปแบบการให้เครดิต เพราะยังไม่พบเงื่อนไขการใช้ feed ที่เผยแพร่ไว้ ข้อมูลของ POPNIX ใช้ได้ตาม[เงื่อนไข Open API](https://flood.pop.in.th/api/) โดยต้องให้เครดิต (มีอยู่ใน footer แล้ว)

ข้อมูลครอบคลุมเฉพาะจุดที่มีการรายงาน (ส่วนใหญ่เป็นทางหลวง) ไม่มีรายงานไม่ได้แปลว่าถนนแห้ง หน้าเว็บจึงแนะนำสายด่วนกรมทางหลวง 1586 และกรมทางหลวงชนบท 1146 ไว้ด้วย

Valhalla และ Photon เป็นเซิร์ฟเวอร์สาธารณะสำหรับการใช้งานปริมาณน้อย ถ้ามีผู้ใช้มาก ควรตั้ง Valhalla/Photon เองหรือใช้บริการแบบเสียเงิน (แก้ URL ที่ `server.mjs` และ `assets/js/route.js`)

## วิธีรัน

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
npm start            # หรือ node server.mjs
# เปิด http://localhost:8080  (เปลี่ยนพอร์ตด้วย PORT=3000 npm start)
```

`server.mjs` serve ไฟล์ static และ proxy ข้อมูลทั้งสองแหล่งพร้อม cache 60 วินาที (ถ้าต้นทางล่มชั่วคราวจะตอบข้อมูลล่าสุดที่มี) feed ของ Longdo ส่ง CORS มาด้วย จึงเปิด `index.html` บนเว็บ static อย่างเดียว (เช่น GitHub Pages) ได้ แต่จะไม่มีข้อมูลเซ็นเซอร์ กทม.

## Deploy บน Render

1. New + → **Web Service** → เลือก repo `medtrackq/roadflood`
2. Branch: `main` · Runtime: **Node** · Build Command: `npm install` · Start Command: `npm start` · Instance: **Free** · Region: Singapore
3. กด Create แล้วรอจนขึ้น "Deploy live"

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้ารายงานน้ำท่วม |
| `route.html` | หน้าวางแผนเส้นทาง |
| `assets/js/floods.js` | โหลดรายงาน, แปลงข้อมูล, จัดระดับความเสี่ยง (ใช้ร่วมกัน 2 หน้า) |
| `assets/js/route.js` | ค้นหาสถานที่, หาเส้นทาง, ตรวจจุดน้ำท่วม, หาเส้นเลี่ยง |
| `assets/css/style.css` | สไตล์ (light/dark) |
| `assets/js/roads.js` | ดึงข้อมูล แยกสถานะ ค้นหา/กรอง แผนที่ และรายการ |
| `server.mjs` | static server + cached proxy (รายงานน้ำท่วม, ค้นหาสถานที่, เส้นทาง) |
